# Metody renderowania wokseli

## Kompilacja

Kompilacja aplikacji testującej wymaga kompilatora języka programowania C++ obsługującego standard 23 oraz systemu budowania CMake o minimum wersji 4.2. Kompilacja przetestowana na systemie Linux.


```
mkdir build
cmake -B build 
cmake --build build
./build/voxel-rendering
```
